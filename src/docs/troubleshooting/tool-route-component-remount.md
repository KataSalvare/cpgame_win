# 工具栏切换路由后原型内容未更新

## 现象

在工具栏左侧导航中切换陪玩平台的首页、俱乐部详情和陪玩详情时，导航选中项与地址会变化，但预览主体可能仍显示前一个页面。直接刷新目标地址可以正确显示目标页面，因此问题发生在应用内切换页面时。

## 根因

三个工具栏入口复用同一个原型组件。React Router 切换路由时保留了同一组件实例，而原型用 `useState` 初始化函数读取入口参数；初始化函数不会因为入口参数变化而自动重新执行，页面内部路由状态于是仍停留在旧值。

## 修复与约束

- 在 `tools/App.tsx` 的路由元素上使用 `key={page.path}`，使不同工具栏路由对应不同组件实例，切换入口时重新按 `entryView` 初始化原型。
- `tools/config/pages.ts` 中三个入口分别映射首页、俱乐部详情、陪玩详情。
- `src/prototypes/game-companion-client/useClientNavigation.ts` 为直接访问详情入口提供固定 mock 俱乐部与陪玩记录。
- 类似问题优先检查路由元素是否复用了组件实例，以及页面状态是否只在 `useState` 初始化时读取入口参数；若路由切换应重置整页状态，按路由身份重建组件实例。

## 验收记录

应用内依次切换首页 → 俱乐部详情 → 陪玩详情，预览主体分别显示对应内容；直接访问三个工具栏入口时也能落到对应的固定 mock 数据。修复后执行 `npm run lint`、`npm run build` 和 `npm run check:docs` 均通过。构建有既存的大 chunk 体积提示，不影响成功结果。
