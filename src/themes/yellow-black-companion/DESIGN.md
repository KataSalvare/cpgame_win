# 黄黑陪玩平台主题

## 1. 视觉主题

面向 Windows 游戏陪玩客户端的明亮、高密度界面。以品牌黄和深色文字强调操作，以冷灰、白色区分内容层次。基于灰阶原型和消息页着色规范；消息页以外的色彩应用为保守扩展，须通过实际页面样板验证。主题独立于既有灰阶及上色模式。

## 2. 色彩

| brand | #FFD60A | 顶栏、主按钮、己方文字消息 |

| ink | #1D2129 | 主要文字、黄色表面上的文字 |

颜色来自项目着色规范或灰阶主题，交互状态值为本主题保守扩展。普通文字对比度至少 4.5:1，大文字至少 3:1；必要控件边界和状态标识至少 3:1。黄色不可单独作为白底上的焦点或选中标识。状态同时使用文字、图标或形状表达。

## 3. 字体

使用 `"Segoe UI", Arial, sans-serif` 和系统中文回退；等宽字体 `ui-monospace, Consolas, monospace`。页面标题 20px/28px、600；组件标题 16px/24px、600；正文 14px/20px、400；辅助文字 12px/18px、400；控件 14px/20px、600。必要小字使用 secondary 色。

## 4. 组件

- 主按钮与同级的次要、浅灰和危险操作按钮统一高度 48px，横向内边距 16px，胶囊圆角 9999px；主按钮黄底深字，次按钮白底深色边框。禁用有明确文字和不可操作状态。危险操作为白底红字并说明后果。
- 输入框高度 36px，白底、1px control-border、6px 圆角；聚焦时使用沿控件内侧的 2px 深灰边界，不叠加外环；错误态聚焦使用 2px 红色边界。错误显示文字和红色边框；标签始终存在。
- 导航与筛选项采用圆角形态。导航项高度 40px，选中项白底、左侧深色标记和加粗文字；悬停使用独立浅灰背景。
- 卡片白底、8px 圆角、1px border、16px 内边距；特殊分享卡可用浅黄底。标签用文字与图标补足颜色。
- 消息气泡 8px 圆角、12px 内边距；对方白底，己方黄底深字，以左右位置和头像辅助区分。
- 表格表头、行与分隔线保持清晰；标准公共弹窗宽 375px（可用空间不足时不溢出）、白底、8px 圆角、16px 内边距；标题居中，标题与正文、正文与按钮之间各间隔 20px；双按钮等宽横排、间距 11px、左取消右确认，单按钮铺满操作区；操作按钮高 48px 且为胶囊圆角，取消使用白灰色液态玻璃、确认使用黄色液态玻璃；危险操作保留红色语义，菜单独立白底与浮层阴影。
- 内容须知弹窗复用 375px 标准弹窗，可放置图片或其他须知内容，底部单个 48px 黄色液态玻璃主按钮占满内容宽度；“不再提醒”可选项位于白色面板下方的遮罩上，勾选状态与持久化由业务页面管理。内容尺寸和图片比例由素材决定，展示样例中的灰色区域仅示意。
- 图标提示弹窗用于余额不足、支付确认、购买及资产操作结果等场景。内容依次居中排列图标、标题和说明，右上角保留关闭按钮；不影响普通确认弹窗。标准宽度 375px，白底、8px 圆角、柔和浮层阴影；图标容器 112 × 96px，图标与标题间隔 8px；标题 20px/28px、600，说明 14px/22px，标题与说明间隔 8px，说明与操作区间隔 20px。左右内边距与底部内边距为 24px，顶部为 24px；双按钮等宽、高 48px，左侧白灰液态玻璃次操作、右侧黄色液态玻璃主操作，阴影比页面按钮更轻。插图使用适合业务语义的透明背景 WebP，单张不超过 100KB；灰阶原型使用灰阶显示。金额、风险与结果仍须通过文字说明，不依赖图标传达。
- 所有可交互组件支持默认、悬停、按下、禁用、键盘焦点；可选组件另有选中状态。选中和悬停可同时识别，焦点不依赖黄色。交互组件使用原生语义与可访问名称。

### 液态玻璃按钮

首页操作和钱包资产操作使用 `GlassButton`：主操作为半透明品牌黄渐变，次操作为半透明白灰渐变，胶囊圆角、无描边，以内高光、柔和阴影和背景模糊形成层次。支持悬停、按下、禁用及深色键盘焦点；减少动态效果时关闭过渡。默认高度 48px，局部布局可调整尺寸。灰阶预览保留原有按钮外观。

## 5. 布局与间距

业务原型固定 1920×1080 CSS 像素，标题栏 40px，导航 240px，内容两侧 24px；工作台只等比缩放。基础间距 4px，常用 8、12、16、24、32px；卡片间距 16px。主题组件样例保持实际 CSS 尺寸，不对样例整体缩放。

## 6. 边框与深度

普通分隔线 1px #E5E6EB；必要边界 1px #86909C。卡片阴影 `0 1px 3px rgba(17,24,39,.06)`；浮层 `0 8px 24px rgba(17,24,39,.15)`。按钮等控件焦点环 `2px solid #1D2129`、偏移 2px；输入框焦点沿内侧边界显示，普通态 `#4E5969`，错误态 `#C9362B`，宽 2px。避免发光和厚重阴影。

## 7. 动效

颜色和边框过渡 120–160ms；不以动画替代状态信息，避免弹跳、视差和持续循环。`prefers-reduced-motion: reduce` 时移除非必要过渡。

## 8. 响应式

业务原型保持固定桌面布局，无移动端断点重排；工作台按可用空间等比缩放。主题展示页随可用空间换行，但组件自身尺寸不缩放，必要时局部滚动。

## 9. Prompt guide

推荐：使用品牌黄主操作和深色文字；用冷灰和白色组织消息界面；使用 4px 间距体系；选中和焦点同时使用形状或明暗表达；遵循现有业务页面结构。

避免：黄色文字放在白底；浅灰小字承担必要信息；把普通卡片统一涂黄；把截图内容当作业务规则；大面积霓虹、厚重阴影和装饰性动效。

生成提示：为 1920×1080 Windows 游戏陪玩客户端使用黄黑陪玩平台主题，标题栏 40px、导航 240px，使用 #FFD60A、#1D2129、#F6F7FD 和白色建立层级，保留可辨认的状态、键盘焦点和现有业务流程。

### 移动端参考的桌面组件变体

用户提供的移动端组件图中包含胶囊主按钮、浅灰次按钮、浅灰输入区与黄色选中边框。桌面主题统一使用胶囊形操作按钮，并提供浅灰次按钮变体，尺寸仍以桌面规范为准；不将移动端底部弹层、窄屏布局和业务字段直接套用到 Windows。品牌插画、头像与会员图标需使用确认后的素材。
