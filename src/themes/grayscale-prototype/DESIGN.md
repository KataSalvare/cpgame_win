# 灰阶原型设计规范

## 1. 视觉主题与氛围

「灰阶原型」用于 Windows 客户端产品原型，表达简洁、规整、低保真的产品界面。它适合流程、信息架构和交互评审，不追求最终品牌视觉或拟真质感。

- 基准画布：1920×1080 CSS 像素。
- 窗口结构：顶部标题栏 + 左侧导航 + 主内容区。
- 气质关键词：中性、清晰、紧凑、可评审。
- 信息层级主要通过灰阶、间距、边框和字体区分。
- 不使用装饰性插画、渐变、纹理或强烈品牌表达。

## 2. 色彩系统

| Token | 色值 | 用途 |
| --- | --- | --- |
| Canvas | `#F3F4F6` | 主画布背景 |
| Surface | `#FFFFFF` | 卡片、面板和弹层 |
| Border | `#E5E7EB` | 默认细边框和分隔线 |
| Text | `#1F2937` | 标题、正文和主要信息 |
| Text muted | `#6B7280` | 辅助说明、占位文字和次要信息 |
| Primary action | `#374151` | 主按钮背景 |

- 主按钮文字使用白色，确保与按钮背景有清晰对比。
- 成功、警告、错误和禁用状态均使用灰阶。
- 状态通过图标、文字标签、边框明暗和控件状态共同表达，不依赖颜色。
- 不引入彩色状态色或额外品牌强调色。

## 3. 字体系统

- 字体角色：系统无衬线字体。
- 字体栈：`"Segoe UI", Arial, sans-serif`。
- 页面标题：20px，字重 600。
- 正文与菜单：14px，字重 400。
- 辅助信息：12px，字重 400。
- 控件文字：14px，字重 600。
- 行高以 1.4–1.5 为主；避免过小字号和过密行距。

## 4. 组件规范

### 窗口与导航

- 顶部标题栏高 40px，包含应用标识或标题以及窗口控制区域。
- 左侧导航宽 240px，从标题栏下方延伸至窗口底部。
- 当前导航项使用浅灰填充、加深文字或左侧细标记表现选中状态。
- 导航分组之间使用留白或细分隔线，不使用彩色图标。

### 页面与操作

- 主内容区顶部默认包含页面标题和主要操作按钮。
- 次要操作使用白色背景、灰色边框和深灰文字。
- 主按钮使用 `#374151` 背景与白色文字。
- 按钮和输入框使用 6px 圆角，最小高度建议为 32px。
- 输入框使用白色背景、1px `#E5E7EB` 边框；聚焦时加深边框并显示清晰焦点环。

### 锚定浮层

- 筛选、更多选项等按钮可在 hover 时触发锚定浮层；键盘 focus 也应能打开相同浮层。
- 指针从触发按钮移入浮层时保持打开；指针与键盘焦点都离开按钮和浮层组成的整体交互区域后关闭，避免按钮和面板间的间距导致闪烁。
- 浮层默认使用白色表面、1px 淡灰边框、8px 圆角和克制阴影；常规宽度为 320px，按触发按钮附近定位。
- 触屏设备不依赖 hover，由调用方提供点击开合；调用方负责浮层显示状态与事件。

### 卡片与状态

- 卡片使用白色背景、1px `#E5E7EB` 边框和 8px 圆角。
- 卡片内部分组使用细分隔线或间距，不使用重阴影。
- 成功、警告和错误状态使用图标、标签文字和灰阶边框区分。
- 禁用状态降低文字与边框对比度，同时保留可读性。

## 5. 布局与间距

- 画布固定为 1920×1080 CSS 像素。
- 标题栏高 40px，左侧导航宽 240px。
- 主内容区占据剩余空间，内容区两侧留白为 24px。
- 页面标题与内容之间使用 16–24px 间距。
- 卡片之间使用 16px 间距。
- 基础间距单位为 4px，常用间距为 4、8、12、16、24、32px。
- 主内容可在自身区域内滚动；标题栏和左侧导航保持固定。

## 6. 深度、阴影与边框

- 默认分隔使用 1px `#E5E7EB` 细边框。
- 卡片阴影：`0 1px 3px rgba(17, 24, 39, 0.06)`。
- 弹层可使用略强于卡片的阴影，但仍保持克制。
- 不使用发光效果、厚重投影、多层阴影或渐变描边。
- 焦点状态需要清楚可见，可使用深灰边框与 2px 浅灰外环。

## 7. 动效

- 低保真原型优先使用即时反馈。
- Hover、聚焦和按下状态可使用 120–160ms 的颜色或边框过渡。
- 不使用弹跳、视差、持续循环或装饰性动效。
- 页面状态变化应清晰，不用动效代替状态提示。
- 用户系统启用减少动态效果时，应移除非必要过渡。

## 8. 响应式行为

- 主题按固定 1920×1080 桌面画布设计，不切换为移动端布局。
- 预览区域变小时，只等比缩放画布；内部尺寸与排布保持不变。
- 不使用会改变基准布局的断点重排。
- 主内容区域可独立滚动，标题栏和左侧导航保持固定。

## 9. Prompt guide

### 推荐写法

- 使用浅灰画布、白色卡片和淡灰细边框组织 Windows 客户端界面。
- 保持 1920×1080 画布、40px 标题栏和 240px 左侧导航。
- 使用紧凑规整的布局，内容区留白 24px，卡片间距 16px。
- 用图标、文字和边框明暗表达状态，所有颜色保持灰阶。
- 使用系统无衬线字体、轻微圆角和极淡阴影。

### 避免写法

- 不添加高饱和品牌色、彩色状态标签或霓虹效果。
- 不使用渐变、玻璃拟态、纹理背景或装饰性插画。
- 不把桌面布局改成移动端导航或卡片堆叠布局。
- 不使用大圆角、重阴影或夸张动效。
- 不把低保真原型做成高拟真营销页面。
