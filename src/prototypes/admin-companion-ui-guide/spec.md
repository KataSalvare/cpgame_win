# SPEC：黄黑陪玩平台 UI 说明

- 对象类型：后台原型；目录：`src/prototypes/admin-companion-ui-guide/`；分类：admin。
- 画布：1920 × 1080 CSS 像素。三个路由分别展示色彩与按钮、输入与选择、弹窗与标签。
- 展示基于黄黑主题 `DESIGN.md`、主题组件及客户端高保真标准弹窗规范；尺寸和色值以各样例说明及对应源码为准。各业务场景可能存在局部尺寸变体。
- 页面为静态规范样本，筛选、开关和下拉菜单仅在本地交互，不连接服务端。仅提供正常状态。
- PRD 由产品负责人维护；示例文字不定义业务规则。

## 0. 关联信息

三个页面的路由分别为 `/admin/companion-ui-foundations`、`/admin/companion-ui-forms` 和 `/admin/companion-ui-overlays`，页面 PRD 分别位于 `src/docs/page-prds/`。

## 原型与正式开发边界

色值和尺寸来自黄黑主题及客户端高保真规范，展示数据为本地静态示例。

正式产品的交互、校验和数据持久化由业务实现。说明页面的开关、分段与菜单仅用于本地演示。

## 消息样式说明页

`/admin/companion-ui-messages` 复用客户端聊天消息组件和高保真样式，展示文字、图片、语音、表情、礼物、引用、撤回、陪玩名片、房间分享、订单、客服评价以及系统和群通知。内容仅为示例；语音播放为本地状态演示，不播放实际音频。

## 浮层面板说明页

`/admin/companion-ui-panels` 展示个人快捷面板、一键匹配面板、录屏悬浮面板，以及匹配和语音房最小化样式。个人快捷面板及匹配面板复用原组件；录屏及缩小态为同类样式的静态展示，录屏按钮只演示暂停状态。

## 核心框架说明页

`/admin/companion-ui-framework` 使用客户端窗口框架、标题栏、导航和侧栏抽屉组件，展示 1920 × 1080 画布、栏位、滚动和高保真表面。整窗样例按 60% 展示，标注为原始 CSS 尺寸；示例内容不构成业务需求。

液态玻璃按钮与面板的说明区提供与现有组件对应的渐变、透明度、模糊、阴影和交互状态 CSS，供开发交接；展示代码中的类名为独立示例。
