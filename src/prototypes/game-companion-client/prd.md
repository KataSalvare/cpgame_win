# 游戏陪玩平台 Windows 客户端 PRD

## 1. 产品定位

- **对象类型**：前端原型
- **用户**：寻找俱乐部与陪玩的玩家
- **平台**：Windows 桌面客户端，1920×1080 CSS 像素画布
- **目标**：让玩家浏览游戏、俱乐部和陪玩服务，完成下单演示、账户管理，并通过 IM 和语音房与好友沟通及组队。
- **当前原型范围**：首页、俱乐部详情、陪玩资料、下单结算、个人中心、钱包、订单、消息和语音房。客服、关注、拉黑、打赏、充值及所有服务端通信仍不接入真实业务。

## 3. 内容与交互约束

- 首页俱乐部范围初始为「推荐俱乐部」，游戏范围初始为「全部游戏」。俱乐部范围是推荐、我关注的俱乐部或单个标签之一；俱乐部标签单选。游戏与俱乐部范围筛选同时生效。
- 年龄选项：18–25 岁、26–30 岁、31–35 岁、36–40 岁、41 岁及以上。
- 陪玩筛选每个字段单选，各字段组合生效。服务列表游戏筛选单选，默认全部游戏。
- 服务排序：综合排序、价格从低到高、价格从高到低、单数从低到高、单数从高到低。
- 首页点击俱乐部进入俱乐部详情；点击陪玩后使用公共 WindowsClient 右侧面板展开第三栏，切换陪玩时保持俱乐部详情不变。内部路由为 `#page=home|club-detail&club=<id>&companion=<id>`，关闭第三栏后保留当前俱乐部详情。
- 每个页面的异常状态提供本地重试反馈；空状态提供返回或清除筛选的路径。
- 下单结算为单页流程，单笔订单仅包含一项服务；服务价格按“钻石/小时”展示，时长选项为 1、2、3、4 小时。时长与单价相乘得出演示金额，不选择预约时间。
- 演示支付成功后，本地余额扣减并在订单列表新增“待接单”记录；不调用真实支付或持久化接口。余额不足时仅提供跳转钱包入口。
- “我的钱包”同页展示两个钱包；明细在对应钱包卡片下展开。钻石充值入口只展示“充值页暂未纳入本次原型”的本地反馈。
- 我的订单使用单一列表和状态下拉筛选。常用设置入口与退出登录按钮只反馈“本次原型未包含该页面/未更改登录状态”。
- 消息入口包含会话和好友；消息类型含文字、表情、示例图片和示例语音。群聊创建需填写群名称、选择至少两位好友；群内可以继续邀请好友。
- 语音房入口和消息入口独立。房间包含独立文字聊天；房间创建仅设置名称与公开/私密。新房间默认创建“主频道”，每个子频道展示 8 个固定麦位。
- 语音房房主可新增、改名、删除子频道；删除子频道时，成员被移至其他有空位的子频道。房主/管理员可拖动成员切换子频道，普通成员可通过点击频道自行切换。
- 语音房房主/管理员可移出成员和禁言，只有房主可分配管理员或转让房主。邀请由独立弹窗选择好友，接收邀请显示在语音房入口；私密房仅通过邀请进入，邀请不会发到 IM。

## 4. 真实数据交互逻辑

正式产品需要使用正式游戏目录、俱乐部与陪玩档案、关注关系、服务配置、接单状态、评价和礼物数据，并依据后续确认的数据模型与服务接口实现筛选、排序和读写。IM、好友关系、群聊成员、房间可见范围、房间成员角色、子频道容量、邀请通知和语音连接的正式数据模型、权限及服务端行为均待正式文档确认。本轮只在本地 mock fixture 上演示展示和交互；不从 mock 结果推导真实业务规则、权限、价格或状态流转。

## 7. 验收标准

- **AC-01-01**：首页与俱乐部详情显示相同内容和样式的 Banner；自动轮播，上一张/下一张和指示点均可手动切换。
- **AC-01-02**：首页默认推荐俱乐部和全部游戏；切换游戏、推荐/关注范围或单个标签后列表按组合条件更新。
- **AC-01-03**：首页俱乐部卡片包含约定字段；点击详情入口进入对应俱乐部详情，返回路径可回到首页。
- **AC-01-04**：首页选择俱乐部后进入俱乐部详情；俱乐部页展示资料、操作入口和陪玩卡片。点击陪玩后公共右侧栏展开资料、服务、评价和礼物；点击另一位陪玩仅更新该栏数据，俱乐部详情保持不变。
- **AC-01-05**：俱乐部陪玩列表筛选条件可组合；五种排序方式正确重排结果。
- **AC-01-06**：陪玩详情显示约定资料与操作入口，操作入口不触发下单、关注、拉黑、聊天或送礼流程。
- **AC-01-07**：服务游戏单选；服务字段完整；每页最多 20 条，可分页，不采用无限滚动。
- **AC-01-08**：服务/评价/礼物三个页签可切换；俱乐部详情的返回导航和抽屉内页签随各自内容滚动吸顶；第三栏抽屉标题与关闭按钮固定，抽屉内容独立滚动。
- **AC-01-09**：三页均可预览正常、加载、空、异常四种状态；错误可重试，空状态有明确返回/恢复路径。
- **AC-01-10**：首页与俱乐部详情使用 Windows 桌面客户端布局；陪玩详情展开为公共 WindowsClient 第三栏，关闭后回到两栏布局。
- **AC-02-01**：陪玩详情中点击服务下单后进入结算页；结算页展示所选陪玩和服务，可切换 1–4 小时，且不出现预约时间选择。
- **AC-02-02**：结算页按 mock 单价 × 时长显示应付钻石、当前钻石余额和确认支付入口。
