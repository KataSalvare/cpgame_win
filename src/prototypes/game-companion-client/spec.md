# 游戏陪玩平台 Windows 客户端 SPEC

## 0. 关联信息

- **所属 PRD**：`prd.md`
- **页面 / 路由 ID**：`game-companion-client` / `/game-companion-client`

- **目标平台与画布**：Windows 桌面客户端；1920×1080 CSS 像素，工作台等比缩放
- **设计规范来源**：`/src/themes/grayscale-prototype/DESIGN.md`

## 2. 页面与交互

### 2.1 首页 `home`

- Banner 由本地运营示例配置，自动轮播并支持箭头和指示点手动切换；切换 Banner 不模拟未确认的业务跳转。
- 游戏入口单选；默认「全部游戏」。
- 俱乐部范围为推荐、我关注的俱乐部或一个俱乐部标签，单次选择一个范围/标签；与游戏筛选组合。
- 俱乐部卡片展示头像、名称、ID、自营标记、评分、标签、简介、陪玩人数和详情入口。
- 点击俱乐部卡片进入俱乐部详情；返回路径回到首页。
- 工具层导航提供首页、俱乐部详情、陪玩详情三个独立入口；直接进入俱乐部详情固定展示 `club-001`，直接进入陪玩详情固定展示 `companion-001` 及其所属俱乐部。

### 2.2 俱乐部详情 `club-detail`

- 顶部在返回路径后展示与首页相同的运营 Banner；复用相同内容、灰阶样式、7 秒自动轮播、上一张/下一张和指示点手动切换，不模拟未确认的业务跳转。
- 顶部复用俱乐部卡片资料字段；展示接待大厅、价目表、尊享卡、客服、自助下单、优惠券、群聊按钮，但不展开对应流程。
- 陪玩列表为三列卡片；游戏筛选使用与首页一致的单选按钮，接单状态、性别、地区和年龄以单选下拉筛选，条件可组合；可按五种既定规则排序。
- 陪玩卡片点击后在 `WindowsClientFrame.rightPanel` 展开第三栏详情；保持俱乐部详情及筛选列表不变。
- 点击同一栏中其他陪玩只更新被选陪玩的资料和服务内容，不触发整页路由切换。
- 关闭第三栏后回到保留原筛选状态的俱乐部详情。

### 2.3 陪玩详情（俱乐部详情中的第三栏）

- 作为第三栏展示头像、昵称、性别、年龄、ID、评分、状态、多个标签、个人简介。
- 拉黑、关注、聊一聊、打赏送礼只显示按钮，不触发流程。
- 服务/评价/礼物三个页签吸顶；服务页按单个游戏筛选，每页 20 条并显示分页控件，不使用无限滚动。
- 服务项展示游戏图标、游戏名称、玩法名称、等级名称、服务单数、服务评分、钻石单价（本原型按小时展示）和下单按钮；点击后进入对应服务的结算页。

### 2.4 下单结算 `checkout`

- 从陪玩服务项进入，URL hash 携带 `companion` 和 `service`；独立预览入口使用默认陪玩及其首个 mock 服务。
- 单页展示陪玩、游戏、服务、等级和 mock 单价；服务时长选择 1、2、3、4 小时，不选择预约时间。
- 应付钻石按 mock 单价 × 时长计算；同页展示钻石余额和确认支付操作。
- 余额不足显示差额和前往钱包入口；余额足够时显示本地提交成功反馈，扣减本地余额，并新增一笔“待接单” mock 订单。
- 返回按钮回到俱乐部详情并保留陪玩第三栏。支付反馈仅用于演示，不产生真实交易。

### 2.5 个人中心 `profile`

- 通过左侧“个人中心”、标题栏头像/昵称或侧边栏“玩家中心”进入。
- 展示头像、昵称、性别、朋友数、关注数、粉丝数；展示钻石与糖豆余额概览、钱包总览和订单入口。
- 常用设置展示账号安全、通知设置、隐私设置和退出登录；点击显示本地提示，不进入设置页或改变登录状态。

### 2.6 我的钱包 `wallet`

- 同页并列展示钻石钱包和糖豆钱包余额；每个卡片都可展开各自的收支明细。
- 钻石钱包提供充值入口；点击仅显示“充值页面暂未纳入本次原型”，本次不新增充值页。
- 支付成功时更新内存中的钻石余额，并将演示消费添加到钻石明细。

### 2.7 我的订单 `orders`

- 订单混合展示，以状态下拉框筛选全部、待接单、待服务、服务中、已完成和退款。
- 订单卡片展示订单编号、状态、服务、游戏、陪玩、时长、金额和创建时间。
- “待服务”表示已接单但服务未开始；“服务中”表示陪玩服务已开始；不使用“进行中”状态。
- 新下单成功后增加“待接单”演示记录。筛选无结果时提供查看全部订单操作；不提供订单详情、取消或退款处理。

### 2.8 消息 `messages`

- 作为客户端独立导航项，与“语音房”并列；消息页使用会话列表和聊天主区域。会话列表支持全部/私聊/群聊筛选、按名称搜索和未读提示，并可切换至好友列表。
- 页面不展示重复的“玩家社交 / 消息”顶部标题栏；创建群聊入口仅在选择“群聊”筛选后，显示于会话类型筛选下方。
- 好友列表只展示好友和在线状态，不实现添加、删除或备注。点击好友行直接打开该好友私聊，并在右侧同时展开其资料详情。
- 私聊和群聊均展示文字、表情、图片示例和语音示例；文字可本地发送，示例图片可展示，语音播放控件切换本地播放状态。所有媒体交互仅用于演示。
- 点击聊天对象头像、消息发送者头像或群成员头像后，在聊天右侧展开用户资料面板；好友关联陪玩资料时复用陪玩详情的完整侧栏，包含头像资料卡、服务/评价/礼物页签与列表，以及拉黑/关注/聊天/送礼操作。“聊一聊”可进入该用户私聊，服务项可进入下单；关闭资料栏后保留当前会话。好友关联和陪玩服务均为本地 mock 映射。
- 群聊中点击聊天标题旁的群头像，在右侧第四栏打开群聊设置；面板可查看成员、修改群名称或邀请好友。点击设置面板中的成员头像仍打开统一的用户资料面板。
- 创建群聊需填写群名称并选择至少两位好友；创建后可通过群成员头像区或群聊设置面板的邀请入口选择未入群好友。邀请与群消息仅本地演示。

### 2.9 语音房 `voice-room`

- 与“消息”并列的独立导航项。页面按参考截图采用房间/子频道树、语音麦位区、房内文字聊天三栏布局，遵循灰阶主题。
- 页面不展示重复的“好友一起开黑 / 语音房”顶部标题栏；邀请入口放在语音房第一栏，未处理邀请在该栏显示提示和未读数，可接受或忽略。私密房邀请不进入 IM。
- “语音分组”标题右侧提供“创建分组”入口；创建分组填写名称和公开/私密，并自动生成主频道。每个分组标题右侧提供“创建子频道”入口，只对该分组房主显示，并在对应分组内新建。房间分组标题可点击折叠或展开子频道列表；每个子频道也有独立折叠控件，只折叠左栏中的成员列表，点击频道名称仍切换当前频道。房主可修改房间名称/隐私以及改名和删除子频道。
- 每个子频道展示 8 个固定麦位。成员可加入/离开语音、上麦/下麦及静音；麦位空缺与成员状态即时更新。
- 房主和管理员可以拖动其他成员至同房间的其他子频道；普通成员可点击子频道切换。目标子频道满 8 人时不接受移动。删除有成员的子频道时，把成员移动到其他有空位的子频道。
- 房主/管理员可移出成员或禁言；房主可设置管理员或转让房主。权限仅按本地 mock 的当前玩家角色决定。
- 每个房间拥有独立的文字记录；房内消息不出现在 IM 会话列表，切换房间时展示各自记录。房间聊天本轮只演示文字发送。
- 正式实时语音、麦克风采集、房间服务端持久化及权限规则不在原型范围内。

## 3. 页面级状态

状态通过原型浏览工具的页面状态面板切换，不在原型主体内显示状态控制。

| 状态 ID | 触发条件 | 页面表现 | 操作与恢复 |
|---|---|---|---|
| `PS-01` 正常 | 默认 | 展示对应页面及 mock 数据 | 筛选、排序、分页、页签切换、下单和页面导航可用 |
| `PS-02` 加载 | 工具选择加载中 | 对应页面展示灰阶骨架与加载状态 | 等待页面状态切换 |
| `PS-03` 空 | 工具选择空数据 | 对应页面展示空状态 | 首页可返回默认筛选；详情页可返回上一级 |
| `PS-04` 异常 | 工具选择异常 | 对应页面展示错误说明与重试入口 | 重试恢复正常态 |

所有九个页面（首页、俱乐部详情、陪玩详情、下单结算、个人中心、钱包、订单、消息、语音房）都实现四种页面状态：消息页关联 `FR-26`、`AC-03-05`；语音房页关联 `FR-35`、`AC-04-08`；其他页面关联 `FR-11`、`FR-20`、`AC-01-09`、`AC-02-07`。

交易页面业务变体：

| 状态 ID | 触发条件 | 页面表现 | 操作与恢复 |
|---|---|---|---|
| `PS-05` 余额不足 | 应付钻石高于 mock 余额 | 显示差额及前往钱包入口，禁用支付提交 | 前往钱包查看余额；充值页未实现 |
| `PS-06` 演示支付成功 | mock 余额足够并确认支付 | 展示订单编号；本地扣减余额并新增待接单订单 | 可前往我的订单或返回陪玩详情 |
| `PS-07` 提交中 | 不适用；本地演示即时完成，无异步提交等待 | 无独立处理中画面 | 正式支付流程待真实接口与状态文档定义 |

用户角色/权限状态：不适用；本原型固定展示一个玩家示例账号，不模拟身份认证或权限控制。

## 4. 布局与视觉

- 公共外框使用 `WindowsClientFrame`、`WindowsTitleBar`、`WindowsSidebar`；陪玩详情通过 `WindowsClientFrame.rightPanel` 展开第三栏。
- 标题栏高 40px，侧边栏宽 240px；陪玩资料从列表进入，侧边栏保持不变。
- 主内容列最大宽度 1280px，在主工作区居中；内容区纵向滚动。
- 首页 Banner 和游戏区域在上，筛选在俱乐部卡片列表上方；俱乐部卡片三列。
- 俱乐部详情在返回路径后复用首页 Banner，再展示俱乐部资料和操作入口，其次为筛选/排序与三列成员卡片；打开陪玩资料时主列表保留。
- 俱乐部详情的返回导航随主内容滚动吸顶。
- 陪玩资料通过公共 `RightDrawer` 在第三栏展示；抽屉标题和关闭按钮固定，抽屉内容独立滚动。服务/评价/礼物页签在抽屉内容滚动时吸顶；切换成员只更新第三栏。
- 下单结算采用服务内容与支付摘要双栏布局；个人中心采用资料、资产概览、订单入口和设置分区；钱包使用双卡片并列布局；订单使用状态筛选加纵向混合列表。
- 左侧导航新增个人中心、我的钱包、我的订单；标题栏头像/昵称和侧栏玩家中心入口可打开个人中心。工作台配置独立注册四个新增内部页面预览路径。
- 左侧导航另有“消息”和“语音房”两项；工作台为二者注册独立预览入口。消息页使用会话/好友列表与聊天区，资料面板由头像点击展开；语音房页使用房间/子频道树、麦位区和独立房间聊天三栏。
- 语音房每个子频道 8 个麦位；子频道成员列表作为拖放源/目标。管理操作使用文字按钮，房间角色由示例房间分别展示房主、管理员和普通成员。
- 使用浅灰画布、白色表面、淡灰边框、灰阶状态和 Segoe UI 系统字体；遵循主题中尺寸、圆角、间距和焦点状态。
- 卡片、导航、窗口、浮层优先复用 `src/components/WindowsClient/`；该原型专属内容组件放入自身 `components/`。
