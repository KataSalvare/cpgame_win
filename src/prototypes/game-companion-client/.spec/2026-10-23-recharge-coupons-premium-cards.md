# 充值、优惠券与尊享卡决策记录

## 已确认的需求

- 扩展现有玩家端 Windows 游戏陪玩客户端，沿用 `src/themes/grayscale-prototype/DESIGN.md`。
- 钱包新增充值、优惠券和我的尊享卡入口。
- 充值流程包括选择钻石档位、选择优惠券、选择微信支付/支付宝/苹果支付。
- 优惠券页按可用、已过期、已使用分类；充值时可选择符合当前档位条件的可用优惠券。
- 一个俱乐部可以提供多种尊享卡。俱乐部详情展示该俱乐部已购买和未购买的卡，玩家可查看权益浮层并购买。
- 钱包的我的尊享卡入口展示玩家拥有的各俱乐部尊享卡。
- 尊享卡使用钻石钱包购买；余额不足时提示差额并提供去充值入口。
- 尊享卡列表卡片展示图片、名称、价格、权益提示按钮、钻石余额和状态。

## 设计决策

- 业务页面放在 `src/prototypes/game-companion-client/`，通过该原型内部路由承载；工具路由增加独立预览入口。
- 复用现有 Windows 客户端外框、灰阶主题与双栏账户布局。充值为档位/优惠券加支付摘要布局；优惠券使用状态页签；尊享卡使用双列图文卡片；权益通过页面内遮罩浮层展示。
- 页面状态使用工具栏提供的正常、加载、空、异常状态。
- 档位、折扣门槛/金额、尊享卡图片、价格和权益采用本地演示数据；充值和卡片购买更新本地余额、钱包明细、优惠券和持有状态。支付方式不连接真实支付渠道。

## 待正式业务资料确认

- 正式充值档位、支付渠道规则、优惠券适用范围与抵扣规则。
- 尊享卡的价格、有效期、权益、续购/叠加规则及服务端状态。
