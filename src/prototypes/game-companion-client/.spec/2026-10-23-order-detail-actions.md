# 订单详情操作调整决策

## 已确认需求

- **对象类型**：前端原型
- **内容位置**：`src/prototypes/game-companion-client/`
- **路由分类**：frontend
- 在订单列表右侧第三栏查看订单详情，并可快速切换订单。
- 点击“联系陪玩”直接进入该订单陪玩的 IM 私聊。
- 点击“取消订单”后先二次确认；确认后本地状态变更为“已取消”。
- 点击“确认完成”后先二次确认；确认后本地状态变更为“已完成”。
- 其他操作沿用原型提示，不更新订单数据。

## 设计决策

- 继续采用 `/src/themes/grayscale-prototype/DESIGN.md` 和 Windows 客户端 1920×1080 CSS 像素画布。
- 取消和完成使用页面内确认弹窗，保留返回操作；状态更新只作用于当前原型内存数据。
- “已取消”加入订单状态筛选；已取消订单仍可联系陪玩。

## 原型边界

- IM 会话、订单状态更新均为本地 mock 状态，不调用真实服务，也不持久化。
- 正式订单取消、完成、状态同步以及 IM 服务规则待正式产品接口与数据模型确认。
