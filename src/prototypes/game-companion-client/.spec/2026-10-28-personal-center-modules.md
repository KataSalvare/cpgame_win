# 个人中心模块迭代决策

## 产品需求

- 对象类型：前端原型；内容位置：`src/prototypes/game-companion-client/`；路由分类：`frontend`。
- 玩家个人中心包含个人资料、钱包、订单、我的俱乐部、入驻中心、访问记录和我的礼物。
- 个人中心内侧栏切换模块；钱包和订单不在内侧栏重复出现，改在个人资料页显示摘要，客户端主侧栏快捷入口保留。
- 个人资料支持编辑头像、昵称和性别；账号安全、通知设置、隐私设置、退出登录入口保留在个人资料模块。
- 我的俱乐部展示全部俱乐部；可发起加入/退出；同一时间最多加入一个俱乐部；加入和退出确认后均立即更新状态。
- 入驻中心支持陪玩和俱乐部两类申请。
- 访问记录分为足迹（访问过的用户主页）、访客（访问过自己的用户主页）和进房记录（访问过的语音房）。
- 我的礼物仅展示收到的礼物。

## 设计决策

- 沿用 `src/themes/grayscale-prototype/DESIGN.md`、Windows 客户端框架和 1920×1080 CSS 像素画布。
- 个人中心默认打开个人资料，内侧栏显示五个模块：个人资料、我的俱乐部、入驻中心、访问记录、我的礼物。
- 新增数据和流程只作本地原型演示；正式俱乐部成员规则、入驻字段/审核、访问记录和礼物数据规则待确认。
