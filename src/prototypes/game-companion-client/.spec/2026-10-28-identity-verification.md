# 实名认证流程设计确认

- 确认日期：2026-10-28
- 对象类型：前端原型
- 用户：游戏陪玩平台玩家
- 内容目录：`src/prototypes/game-companion-client/`
- 路由分类：`frontend`
- 设计基底：`src/themes/grayscale-prototype/DESIGN.md`
- 窗口框架：沿用现有 Windows 客户端窗口、侧边栏和内容背景；工作台增加独立“实名认证”入口，客户端内容区不增加认证导航菜单。
- 组件方案：复用 `WindowsClientFrame` 与公共 `DialogPanel`。
- 用户确认流程：法规提示弹窗 → 手机号验证码绑定 → 姓名和身份证号 → 手机扫码人脸核验提示及二维码 → “我已认证” → 认证成功提示；二维码步骤可返回并保留信息。
- 演示边界：手机号限制 11 位数字、验证码限制 6 位数字、身份证号限制 18 个字符，但均不校验具体内容；姓名不能为空；二维码不可扫描；不请求短信、身份或人脸核验服务，不调用摄像头，不持久化身份数据。
- 页面状态：仅正常状态；加载、空、异常不适用，因为流程没有异步请求或数据列表。
- 验收重点：客户端窗口背景保持可见；步骤按顺序切换；上一步保留已填内容；每个弹窗均可关闭；确认后出现成功提示；不发生真实核验或数据上传。
