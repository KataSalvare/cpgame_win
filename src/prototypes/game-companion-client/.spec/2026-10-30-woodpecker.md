# 啄木鸟原型决策快照

- 问题：玩家举报/建议入口、工单字段、我的工单分类和公示展示范围。
- 用户选择：Windows 客户端新增“啄木鸟”菜单，包含“我的啄木鸟”和“啄木鸟公示”两个 Tab；“我的啄木鸟”筛选仅保留全部工单、建议工单、啄木鸟工单，不增加“投诉俱乐部”；初始列表需提供 mock 工单。
- 最终设计决策：沿用灰阶原型主题和 Windows 客户端框架；复用导航、卡片、按钮和 DialogPanel。提交弹窗参考移动端字段：意见建议/啄木鸟（举报）、售后原因、被售后人、最多 200 字补充说明、图片附件、匿名提交，并在匿名选项旁展示 7 天公示期和附件隐私提醒。公示 Tab 支持按被售后人昵称或 ID 搜索，展示匿名默认头像、被售后人头像昵称 ID、处理回复和反馈，不提供详情入口。
- 演示边界：我的工单默认 3 条本地 mock 数据；提交、搜索、反馈和附件均只在页面本地模拟，不连接投诉服务、不上传图片、不持久化；举报数据不自动出现在公示列表。
- 举报对象使用本地 mock 用户目录精确搜索；按完整昵称或 ID 命中后展示头像、昵称和 ID，未命中提示“未找到用户”且不可提交。
- 对象类型：前端原型。内容目录：`src/prototypes/game-companion-client/`。路由分类：`frontend`。
