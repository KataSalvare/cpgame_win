# 服务中订单续单与暂停决策

## 已确认需求

- **对象类型**：前端原型
- **内容位置**：`src/prototypes/game-companion-client/`
- **路由分类**：frontend
- 服务中订单提供续单和暂停操作；现有确认完成与提前结束操作继续保留。
- 续单按订单单价、所选数量和服务单位计算。余额充足时直接支付并更新订单时长、总价和钱包；余额不足时可打开充值弹窗。
- 暂停需二次确认；确认后记录当前服务段结束时间，并将订单状态改为待服务。

## 设计决策

- 续单数量可手动输入，并提供加减按钮；数量为正整数订单单位（小时/局）。弹窗展示单价、应付金额、当前余额及续单后的订单时长和总价，并提供取消与支付并续单操作。
- 续单成功后显示结果反馈；余额不足时展示差额和去充值入口，充值弹窗关闭或完成后回到订单。
- 暂停确认弹窗说明时间记录和状态变化；结束时间使用本地当前时间。

## 原型边界

- 续单只扣减本地 mock 钻石并写入本地钱包流水；暂停只更新当前原型内存中的订单状态与服务分段记录。
- 玩家确认提前结束后，订单主状态仍为“服务中”，界面状态显示“待陪玩确认”，订单仍归入“服务中”筛选；等待期间订单列表快捷操作和详情操作区均不展示其他操作。
- 不调用真实支付、充值、订单服务，也不持久化状态。
- 正式可续数量、暂停后恢复服务、计价精度、退款与状态同步规则待正式产品文档确认。
