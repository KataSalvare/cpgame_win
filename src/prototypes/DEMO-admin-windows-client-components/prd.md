# PRD：Windows 客户端公共组件展示页

## 用户与目标

面向原型开发者和产品评审人员，集中查看可复用的 Windows 客户端框架、导航、浮层、弹窗、抽屉和通知样式，并通过简单控件体验组件状态。

## 范围

- 展示公共组件的结构、标准尺寸和灰阶视觉。
- 展示页自身控制导航选中项、列表选中项、两栏 / 三栏 / 四栏布局、最右栏收起 / 恢复、浮层开合、抽屉模式和通知类型。
- 展示抽屉内容滚动时，顶部标题栏与关闭操作保持可见。
- 展示锚定浮层由按钮 hover 或键盘 focus 触发，并支持点击开合。
- 明确标题栏窗口按钮为静态外观；组件不承担真实系统窗口操作。
- 不迁移或修改现有陪玩平台主页，不连接后端数据。

## 真实数据交互逻辑

此展示页没有真实业务数据交互。正式产品如需展示组件状态，应由业务页面向组件传入真实数据与回调；组件包不定义服务端接口。

## 原型边界

页面仅用本地 React state 演示显隐和模式切换。文案、组件规格和状态卡片为静态内容，不代表生产配置或运行状态。

## 页面需求

1. 使用 1920×1080 Windows 客户端框架，固定 40px 标题栏和 240px 左侧导航。
2. 展示框架尺寸、锚定浮层、标准弹窗、overlay/inline 抽屉以及中性、成功、警告、错误通知。
8. 锚定浮层在指针悬停或键盘聚焦触发按钮时打开；指针移入面板后保持打开，指针和键盘焦点都离开整体区域后关闭；按钮点击也可打开。
3. 展示页可操作控件控制示例显隐和抽屉模式；公共组件自身保持受控。
4. 展示内容可在主内容区域滚动，标题栏和导航保持固定。
5. 两栏展示左导航和居中限宽的主内容，内容最大宽度 1200px，左右保留留白；三栏展示左导航、主内容和详情；四栏在左导航与主内容之间增加列表栏，选择列表项后更新详情栏内容，不离开当前页面。
6. 三栏和四栏的最右侧面板提供收起入口；收起后分别退回两栏和三栏，恢复入口重新展开相应的最右栏。
7. 右侧抽屉的正文独立滚动，顶部标题和关闭按钮固定在抽屉顶部。

## 验收标准

- 路由为 `/demo/admin/windows-client-components`，分类为 admin。
- 可切换导航选中项、打开和关闭浮层、弹窗与抽屉，并切换抽屉模式。
- 四种通知以灰阶区分并可手动关闭；不自动消失。
- 界面遵循灰阶原型 token、系统无衬线字体、24px 内容留白和 16px 卡片间距。
