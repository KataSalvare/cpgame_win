# SPEC：Windows 客户端公共组件展示页

## 0. 关联信息

- 原型目录：`src/prototypes/DEMO-admin-windows-client-components/`
- 路由：`/demo/admin/windows-client-components`
- 分类：admin
- 组件包：`src/components/WindowsClient/`
- 画布：1920×1080 CSS 像素

## 原型与正式开发边界

该页面用于浏览和操作可复用组件样式。交互状态保存在页面本地 React state 中，不读写服务端数据。组件是外观与事件回调的薄封装，不调用操作系统窗口 API，不自动关闭 overlay 或通知。

## 原型数据源

页面结构、描述文字和示例状态均为本地静态内容；交互开合由本地 React state 控制，无 API 或持久化。

## 3. 布局与组件

- `WindowsClientFrame` 充满原型画布，标题栏高 40px，导航宽 240px。
- 三栏由左导航 240px、主内容和右侧详情 360px 组成；四栏在左导航和主内容之间增加默认 240px 的列表栏。
- 两栏由左导航和主内容组成；内容最大宽度 1200px 并在主区域居中，左右留白随可用空间增长。
- 三栏 / 四栏的最右侧面板提供收起按钮。调用方移除 `rightPanel` 后，四栏布局保留左导航、列表和主内容（三栏）；三栏布局退回左导航和主内容（两栏）。主内容应提供恢复操作，重新挂载相应 `rightPanel`。
- 列表项由页面本地 state 控制选中，选择新项后直接更新右侧详情内容，不切换路由。
- 主内容区独立滚动，内边距 24px；区块和卡片间距 16px。
- 列表通过 `navigationPanel` 插槽渲染；右侧面板通过 `rightPanel` 插槽渲染。两栏宽度分别可用 `navigationPanelWidth` 和 `rightPanelWidth` 调整。
- 主内容最大宽度可通过 `contentMaxWidth` 设置；展示页两栏模式使用 1200px，三栏 / 四栏模式不限制主内容最大宽度。
- Inline 抽屉由框架的 `rightPanel` 插槽渲染，作为右侧详情栏。
- 抽屉标题栏和关闭按钮固定在顶部；正文在独立滚动容器中滚动，避免长内容将关闭操作滚出可视区。
- Overlay 抽屉和弹窗由框架 `overlayLayer` 插槽渲染，保持在同一 DOM 树内。
- Overlay 标识分别为 `gallery-drawer` 和 `gallery-dialog`，用于批注定位。
- 页面按钮和表单控件提供可见键盘焦点环。
- 锚定浮层由调用方控制状态；触发按钮 hover / focus 或点击时打开。触发按钮和浮层之间保持连续的 hover 区域，避免指针移入面板时提前关闭；指针与焦点都离开整体交互区域后关闭。

## 4. Mock 到真实的映射

本页面不涉及服务端数据或 API。示例文字、列表和通知内容均为静态演示数据。

## 需求与验收映射

| 编号 | 需求 / 页面实现 | 验收 |
| --- | --- | --- |
| US-01 | Windows 客户端框架：40px 标题栏、240px 导航、滚动内容区 | AC-01-01：布局尺寸与滚动行为符合主题规范。 |
| US-02 | 受控导航、锚定浮层、弹窗和两种抽屉布局 | AC-01-02：导航可切换；浮层、弹窗和抽屉可按模式开合。 |
| US-03 | 四种通知状态 | AC-01-03：四类均为灰阶并支持手动关闭。 |
| US-04 | 三栏 / 四栏列表详情结构 | AC-01-04：切换布局后列表和详情均不离开当前页面；选中列表项会更新详情内容。 |
| US-05 | 两栏聚焦内容布局 | AC-01-05：内容限宽并居中显示，主区域两侧保留留白。 |
| US-06 | 最右栏折叠与恢复 | AC-01-06：四栏收起右栏保留三栏；三栏收起右栏退回两栏；恢复操作重现被收起的面板。 |
| US-07 | 抽屉滚动时固定顶部操作 | AC-01-07：滚动抽屉正文时，标题栏与关闭按钮始终可见且可操作。 |
| US-08 | 按钮 hover / focus 触发锚定浮层 | AC-01-08：hover 或 focus 打开；指针移入面板后保持打开，指针和焦点均离开整体交互区域后关闭；点击也可打开。 |

## 原型调色预览

该页面复用工具层「灰阶原型 / 上色原型」切换。上色模式下框架、列表、卡片、输入控件、主按钮和焦点状态继承灰阶主题的上色语义 token；布局尺寸与交互状态保持不变。默认灰阶，切换状态在本次浏览期间保留，刷新后恢复灰阶。
