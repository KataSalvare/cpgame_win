# DEMO 陪玩平台主页 PRD

## 用户与目标

目标用户是正在寻找游戏队友或陪玩的玩家。用户希望快速找到合适的游戏分类、按偏好筛选陪玩，并在下单前通过 IM 沟通。

## 范围

- Must：Windows 客户端主页导航、推荐 Banner、热门游戏入口、陪玩筛选和陪玩列表。
- Must：支持按游戏、陪玩标签、在线状态、关键词和排序筛选展示结果。
- Must：提供收起态 IM 入口；展开后可切换本地示例会话并发送消息。
- 不做：真实下单支付、真实用户认证、在线状态同步、消息服务、未读数同步、实际客服连接。

## 真实数据交互逻辑

正式产品需从游戏目录与陪玩服务读取可用游戏、陪玩档案、实时状态、评分及价格；筛选和排序应由服务端或客户端按正式规则处理。聊天需关联真实用户身份、会话、消息持久化、发送状态和未读状态，具体规则待正式产品需求确认。

## 原型边界与 mock

原型只使用组件内的本地示例数据。筛选、排序、收藏、提示和消息发送均为本地状态，不写入服务端，也不代表真实定价、陪玩资质、在线人数或响应承诺。
