# 项目原型设计

开始设计业务页面时，先读取根目录 `AGENTS.md`、对应原型的 PRD / SPEC，以及 `rules/design-guide.md` 和 `rules/prototype-development-guide.md`。项目事实与默认值以这些文档为准。

- 明确目标平台；未指定时采用项目默认的 Windows 游戏陪玩客户端、1920×1080 CSS 像素画布，用户明确指定移动端或 Web 时按指定平台设计。
- 以父容器组织客户端布局，明确固定区域、内部滚动与弹层边界。工作台显示缩放不改变设计尺寸，浏览器媒体查询也不代表画布尺寸变化。
- 按桌面鼠标和键盘操作规划默认交互；需要窗口标题栏等客户端元素时，由页面需求确定其模拟行为。
- 在 SPEC 中记录平台、基准画布和模拟行为，沿用已有主题与业务需求；主题和资源选择按设计规则处理。
